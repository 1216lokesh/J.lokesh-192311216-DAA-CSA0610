MODULE 1 — STABLE MERGE SORT
MERGE_SORT(A)
BEGIN
  IF length(A) <= 1: RETURN A
  Divide A into left and right halves
  L = MERGE_SORT(left)
  R = MERGE_SORT(right)
  RETURN MERGE(L,R)
END

MERGE(L,R)
BEGIN
  Create empty output
  WHILE both L and R contain items:
      IF L.first.timestamp <= R.first.timestamp:
          append L.first to output; advance L
      ELSE:
          append R.first to output; advance R
  Append remaining items from L and R
  RETURN output
END
Using <= ensures that equal timestamps from the left run are selected
first, preserving the original order (stability).

MODULE 2 — RANDOMIZED THREE-WAY QUICK SORT
QUICK_SORT(A, low, high)
BEGIN
  IF low >= high: RETURN
  Choose a pivot randomly from A[low..high]
  Partition into values LESS than pivot, EQUAL to pivot,
  and GREATER than pivot
  Recursively sort the LESS partition
  Recursively sort the GREATER partition
END
Random pivots provide expected O(n log n) behaviour independent of
the initial ordering; three-way partitioning handles duplicate scores.
A median-of-three pivot is another practical option.

MODULE 3 — FIRST-OCCURRENCE BINARY SEARCH
FIRST_TIMESTAMP(A, target)
BEGIN
  low = 0; high = length(A)       // exclusive upper bound
  WHILE low < high:
      mid = floor((low+high)/2)
      IF A[mid].timestamp < target:
          low = mid + 1
      ELSE:
          high = mid
  IF low < length(A) AND A[low].timestamp = target:
      RETURN low
  RETURN NOT_FOUND
END
This is a lower-bound search: it finds the first position not smaller
than target, then checks whether the timestamp equals target.

MODULE 4 — STRASSEN MATRIX MULTIPLICATION
Divide A and B into four equal blocks:
A11,A12,A21,A22 and B11,B12,B21,B22.

M1 = (A11 + A22)(B11 + B22)
M2 = (A21 + A22)B11
M3 = A11(B12 - B22)
M4 = A22(B21 - B11)
M5 = (A11 + A12)B22
M6 = (A21 - A11)(B11 + B12)
M7 = (A12 - A22)(B21 + B22)

C11 = M1 + M4 - M5 + M7
C12 = M3 + M5
C21 = M2 + M4
C22 = M1 - M2 + M3 + M6
Combine the four C blocks into C and return.

For dimensions not a power of two, pad with zero rows/columns to the
next power of two, multiply, then remove the padding.

RECURRENCES
Merge Sort: T(n)=2T(n/2)+Theta(n) = Theta(n log n).
Quick Sort: best/expected balanced T(n)=2T(n/2)+Theta(n)
= Theta(n log n); worst T(n)=T(n-1)+Theta(n)=Theta(n^2).
Binary Search: T(n)=T(n/2)+Theta(1)=Theta(log n).
Strassen: T(n)=7T(n/2)+Theta(n^2)=Theta(n^(log2 7))
approximately Theta(n^2.807).
